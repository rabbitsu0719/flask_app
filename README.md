# flask_app

Flask 기반 웹 애플리케이션 실습 및 과제 코드를 날짜별로 정리한 프로젝트입니다.  
Python Flask 서버 구성, 라우팅, 템플릿 렌더링, 간단한 프론트엔드 연동 등을 학습하는 것을 목표로 합니다.

---

## 📖 프로젝트 개요

이 저장소는 **Flask 웹 애플리케이션 개발 흐름을 학습하기 위한 실습용 프로젝트**입니다.  
각 디렉토리는 실습 또는 과제 단위로 구성되어 있으며,  
기본적인 Flask 서버 실행부터 HTML / CSS / JavaScript 연동까지 단계적으로 정리되어 있습니다.

---

## 📂 디렉토리 구조

```
flask_app/
├── 001/     # Flask 기본 구조 및 초기 실습

```

## 📦 실행 방법

### 1️⃣ 가상환경 생성 및 활성화 (권장)

```bash
python -m venv venv
source venv/bin/activate   # macOS / Linux
```

### 2️⃣ Flask 설치

```bash
pip install flask
```

### 3️⃣ 앱 실행 (예시)

```bash
python app.py
```

또는

```bash
flask run
```

> 실행 파일명(`app.py`)과 방식은 **각 디렉토리별 실습 내용에 따라 다를 수 있습니다.**
